# Unused 1.3 Restoration

Due to relaxed ProGuard settings, Minecraft 1.3 contains some unused code. This mod makes some of these unused features easily accessible.

This mod requires the Ornithe mod loader for version 1.3-pre-07261249 which can be downloaded from here: https://ornithemc.net/. Simply download a jar from the latest release and drop it into the mods folder.

## Features
- Beta 1.8 dev villages
- Beta 1.7 caves
- Biome previewer
- Coral block
- Infinite liquid source blocks
- Level save conflict screen
- Model texture generator
- Panorama screenshotter
- Potion tester
- Rainforests
- Spawnable "Delay" entity
- /test command
- World generation profiler
